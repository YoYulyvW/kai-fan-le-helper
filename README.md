# 开饭了助手 · Windows

一个可以置顶在其他应用前面的长条小工具，自动读取剪贴板内容并发送到手机"开饭了" App。

## 功能

- 🖥️ **窗口置顶** —— 永远在最前面，不挡视线（480×76 长条）
- 📋 **剪贴板监听** —— 复制抖音分享文本自动解析
- 🔍 **自动发现手机** —— 扫描局域网 8848 端口，不用手动填 IP
- 📤 **一键发送** —— 点发送按钮，手机输入框自动填入
- 🎨 **深色 UI** —— 跟随系统，简洁美观
- 📌 **托盘图标** —— 关闭到托盘，双击恢复

## 使用

### 手机端准备

1. 打开"开饭了" App
2. 设置 → 局域网服务 → **启用局域网输入**
3. 保持 App 在前台

### Windows 端

1. 双击 `KaiFanLeHelper.exe` 运行
2. 窗口出现在屏幕右上角
3. 复制抖音分享文本（比如在微信里）
4. 工具自动解析剧名并显示
5. 点「发送」按钮 → 手机输入框自动填入
6. 手机上点「新增」完成统计

### 拖动

鼠标按住窗口任意位置可拖动到屏幕任何角落。

### 关闭

点「✕」按钮 → 缩到托盘（右下角）
双击托盘图标 → 恢复窗口
右键托盘 → 退出程序

## 构建

已在 GitHub Actions 配置好，push 后自动构建，从 Artifacts 下载 EXE。

## 注意事项

- 手机和电脑必须在**同一 WiFi**
- Windows 防火墙可能拦截局域网扫描，首次运行需允许
- 只扫描 8848 端口，手机端必须用这个端口
