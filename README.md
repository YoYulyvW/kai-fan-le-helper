# 开饭了助手 · Windows

一个可以置顶在其他应用前面的长条小工具，自动读取剪贴板内容并发送到手机"开饭了" App。

## 功能

- 🖥️ **窗口置顶** —— 永远在最前面，不挡视线
- 📋 **剪贴板监听** —— 复制抖音分享文本自动解析
- 🔍 **自动发现手机** —— 扫描局域网 8848 端口 + UDP 广播 + TCP 握手，不用手动填 IP
- 📤 **一键发送** —— 点发送按钮，手机输入框自动填入
- 🔁 **识别后自动推送** —— 可选开关，识别出剧名后自动发送，无需手点
- 🎲 **生成名字** —— 一键生成贴近现实的中文姓名
- ⌨️ **全局热键** —— 默认 F1，任意界面一键生成名字并填入 / 粘贴
- 📌 **快捷映射** —— F2/F3/F4… 一键粘贴固定文本，支持配置文件自定义
- 🚀 **开机自启动** —— 默认开启，可在托盘关闭
- 🖥️ **高分辨率自适应** —— 按屏幕分辨率自动缩放，可在托盘菜单手动调倍数
- 🎨 **深色 / 浅色 UI** —— 跟随系统，可在托盘菜单切换
- 📌 **托盘图标** —— 关闭到托盘，双击恢复

## 使用

### 手机端准备

1. 打开"开饭了" App
2. 设置 → 局域网服务 → **启用局域网输入**
3. 保持 App 在前台

### Windows 端

1. 双击 `KaiFanLe-Helper.exe` 运行（单文件，无需安装）
2. 窗口出现在屏幕右上角
3. 复制抖音分享文本（比如在微信里）
4. 工具自动解析剧名并显示
5. 点「发送」按钮 → 手机输入框自动填入
6. 手机上点「新增」完成统计

### 拖动 / 关闭

- 鼠标按住窗口任意位置可拖动
- 点「✕」→ 缩到托盘；双击托盘图标 → 恢复；右键托盘 → 更多功能

### 全局热键（默认 F1）

| 场景 | 行为 |
|------|------|
| 鼠标在**助手输入框**上 | 生成新名字并**填入输入框** |
| 鼠标在**其它程序**（浏览器 / 微信 / 记事本 / 远程桌面…） | 生成新名字并**自动粘贴**进该程序 |

- 热键在 **任意界面** 生效（本机、RDP / ToDesk / 网易 UU、无界鼠标跨机均可用）。
- 触发时**屏蔽系统原 F1**，不会弹出帮助。
- 可在托盘菜单把热键改为 **F1~F12**，或整体**关闭热键**；设置会保存。

## 快捷映射（F2/F3/F4/F9…）

把常用文本绑定到按键，一键粘贴到当前程序；也等效"手动复制"（命中抖音分享文本会自动解析剧名填入推送框）。

### 配置方式

编辑 **exe 同目录**的 `mappings.txt`（首次运行若不存在会自动生成）：

```
# 以 # 开头是注释
# [按键] 开始一个节点，节点下每行一条内容
# 单条内容 -> 直接粘贴；多条内容 -> 弹窗选择
# F1 固定为"生成名字"，此处写 F1 会被忽略

[F2]
懂车帝

[F3]
易车

[F4]
巨量引擎

[F9]
3.05 :9pm ... 嘉禾  https://v.douyin.com/xxx/ ...
9.46 ... 寸土生禾  https://v.douyin.com/yyy/ ...
```

- **改内容**：每行一条，回车即新增
- **换按键**：改 `[F2]` 里的名字（如 `[F5]`）
- **改完重启程序生效**
- 多条内容按键 → 弹出选择框（**只显示解析出的剧名**，带搜索框，双击选中，内容会保留在剪贴板）

> 💡 **生成名字**：主窗口 🎲 按钮、托盘菜单、全局热键均可触发。姓名为单姓 + 名字（85% 双字名 / 15% 单字名），名字取自近年热门用字，贴近真实取名习惯。

> 💡 **剪贴板实体化**：Windows 剪贴板采用"延迟渲染"，源程序未及时应答时可能粘出**旧内容**。开启后会立即把新文本固化为纯文本，解决"粘出旧的"问题（代价：丢失富文本格式）。**默认为关闭。**

> 💡 **缩放**：默认「自动」会按屏幕分辨率自适应。若仍觉得偏小，可在托盘菜单选更大倍数；设置会保存，重启后仍生效。

## 构建

已配置 GitHub Actions，push 到 `main` 后自动构建，产物为 `dist/KaiFanLe-Helper.exe`（附 `.sha256` 校验，且**自动附带 `mappings.txt`**）。

- 构建环境：Windows + Python 3.8.10 + PySide2 5.15.2.1 + PyInstaller 5.13.2 + keyboard 0.13.5
- 打包模式：`--onefile`（单文件）

## 注意事项

- 手机和电脑必须在**同一 WiFi**
- Windows 防火墙可能拦截局域网扫描，首次运行需允许（项目提供 `init_firewall.bat` 一键配置）
- 只扫描 8848 端口，手机端必须用这个端口
- 若使用了系统代理（如 Clash），局域网请求已自动绕过代理，不会受代理延迟影响
- 若 exe 被 Windows Defender 误报/拦截（PyInstaller 打包程序常见），可将 exe 所在文件夹加入 Defender 排除项

## 常见问题

**Q: 运行时报 `Cannot open PyInstaller archive`？**
A: 这是 exe 被 Windows Defender 拦截或下载损坏导致的。先对比 `.sha256` 校验文件确认完整，再将 exe 所在文件夹加入 Defender 排除项。

**Q: 发送后手机要很久才收到？**
A: 若开启了系统代理（Clash/VPN 等），旧版本会走代理导致 8-10 秒延迟。新版已改用直连（`http.client`）绕过代理，正常应秒达。

**Q: 界面在高分辨率屏幕上太小 / 太大？**
A: 程序会按屏幕分辨率自动缩放；如需微调，右键托盘图标 → 缩放 → 选择倍数。

**Q: 热键 F1 不生效 / 只复制不粘贴？**
A: 热键在任意界面生效，"助手输入框"填框、其它程序自动粘贴。若 F1 被其它程序占用，可在托盘菜单换成 F2~F12。

**Q: 复制后粘出的是旧内容？**
A: Windows 剪贴板延迟渲染所致。开启托盘菜单的「剪贴板实体化」可缓解（本地有效；ToDesk 等远程场景受其自身同步延迟影响，无法根治）。

**Q: 在 ToDesk / 效卫投屏等远程下，按过 F9 后热键失效？**
A: 远程被控端对窗口焦点变化敏感，弹窗弹出可能破坏键盘钩子。程序会在**弹窗关闭后自动重装全部热键**恢复。若仍异常，可尝试重新扫描或重启程序。

**Q: 怎么关闭开机自启动？**
A: 托盘右键 → 取消勾选「开机自启动」；或任务管理器 → 启动 → 禁用 KaiFanLeHelper。

## 更新记录

### 热键系统

- 全局热键默认 **F1**，可改 F1~F12，可整体关闭，屏蔽系统原热键
- 采用**多通道冗余**确保兼容性：
  1. keyboard 库低级键盘钩子（主）
  2. 系统级 `RegisterHotKey`（ToDesk 等场景补充）
  3. `GetAsyncKeyState` 轮询兜底
  并带 **300ms 防抖**与**热键看门狗**（定期检测监听线程存活，自动重装，防止钩子被系统静默移除）
- 粘贴发送采用**扫描码 + 分步发送**（拉长 Ctrl 保持时间），解决远程/无界鼠标下"丢 Ctrl、只剩 v、vvvvv 卡键"
- 焦点判断改用 Win32 前台窗口 / 鼠标位置（该窗口为 `WS_EX_NOACTIVATE`，Qt 的 `hasFocus` 恒真不可用）

### 已解决的问题

| 问题 | 解决方案 |
|------|---------|
| 热键粘贴出重复名字（如"张超张超"） | 过滤重复事件类型 + 300ms 防抖 |
| 热键在 Win7 不生效 | 改用 keyboard 库/低级钩子 |
| 热键在远程桌面/无界鼠标下无效 | 多通道冗余 + 扫描码发送 |
| 粘贴时丢 Ctrl 只出 v / vvvv 卡键 | 分步发送 + 拉长 Ctrl 保持时间 |
| 只能在助手输入框粘贴，其它程序不行 | 焦点判断改用 Win32 前台窗口 + 鼠标位置 |
| 按 F9 后热键集体失效（远程下） | 弹窗关闭后自动重装全部热键 |
| 复制后粘出旧内容 | 剪贴板实体化开关（延迟渲染固化） |
| 局域网请求受系统代理拖慢 | 改用 `http.client` 直连绕过代理 |
